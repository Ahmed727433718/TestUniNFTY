# شو عندي · StudyBrief

تطبيق أندرويد خفيف بيقرأ تقويم Moodle تبعك وبيبعتلك كل صبح ملخص: الكويزات، التسليمات، ومحاضرات اليوم.
Android app that reads your Moodle calendar and sends a morning brief plus reminders before quizzes and deadlines.

## الميزات
- **ملخص صباحي** بوقت تختاره، مع تخطّي الأيام الفاضية إذا بدك.
- **تذكير قبل الكويز أو التسليم** (15 دقيقة، نص ساعة، ساعة، ساعتين).
- **ويدجت** للشاشة الرئيسية بتتحدّث لحالها كل تذكير وكل منتصف ليل.
- **تحليل تقويم متقدم**: الأحداث المتكررة (RRULE / EXDATE)، المناطق الزمنية، أحداث اليوم الكامل والمتعددة الأيام، ومعالجة تغيير التوقيت الصيفي.
- **تصنيف ذكي بالعربي والإنجليزي** (كويز، امتحان، تسليم، محاضرة...)، مع تطبيع الهمزات والتشكيل.
- **واجهة عربية RTL + إنجليزية LTR**، وضع فاتح وداكن، أيقونة متكيّفة ومتوافقة مع الأيقونات الملوّنة (Android 13+).
- **فحص الرابط قبل الحفظ** مع رسالة خطأ واضحة لكل حالة (لا إنترنت، رابط منتهي، مو تقويم...).
- **تنبيهات موثوقة**: تنبيه واحد فقط مضبوط على الأقرب (ملخص / تذكير / منتصف الليل)، بيُعاد ضبطه بعد كل تشغيل وبعد الإقلاع وتغيير الوقت أو المنطقة الزمنية، وبيعوّض ملخص فاته الجوال مطفي (خلال 3 ساعات).

## الخصوصية والأمان
- الرابط (فيه توكن خاص) بيتخزّن **مشفّر** بمفتاح AES-256-GCM داخل Android Keystore.
- روابط `http://` مرفوضة، والتحويلات ما بتنزل من https إلى http، والاتصال بدون نص واضح (network security config).
- رسائل الأخطاء ما بتحتوي الرابط أبداً.
- ما في حسابات، تحليلات، إعلانات، ولا نسخ احتياطي سحابي.
- زر «حذف الرابط والبيانات» بيمسح كل شي ويوقف التنبيهات.

## بناء الـ APK من GitHub (بدون تثبيت شي)
1. أنشئ مستودع جديد على GitHub وارفع كل ملفات المشروع (مجلد `.github` لازم يكون ضمنها).
2. افتح تبويب **Actions** ← **Build APK** ← **Run workflow** (أو بيشتغل لحاله مع كل push).
3. بعد ~5 دقايق افتح التشغيل الأخير ونزّل **StudyBrief-debug-apk** من قسم Artifacts، وفك الضغط ثبّت `app-debug.apk` على جوالك (فعّل «التثبيت من مصادر غير معروفة»).

## البناء محلياً
المتطلبات: Android Studio (Koala أو أحدث) أو JDK 17 + Gradle 8.7+ مع Android SDK 34.

```bash
# أول مرة (بيولّد gradle wrapper)؛ Android Studio بيسوي هالخطوة تلقائياً
gradle wrapper --gradle-version 8.9

./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # اختبارات الوحدة
./gradlew lint
```

نسخة الإصدار (`assembleRelease`) تحتاج keystore للتوقيع.

### اختبارات المنطق بدون Android SDK
المنطق الصافي (التحليل، التصنيف، الجدولة، الشبكة) مكتوب بجافا عادية وبيتفحص بسرعة:

```bash
tools/run-logic-tests.sh       # 75 اختبار JUnit (يحتاج JDK 17+ وjunit-4.13.2 وhamcrest-core-1.3)
python3 tools/check-resources.py   # يتحقق من مراجع R.* وتطابق الترجمتين العربية والإنجليزية وXML
```

## هيكل الكود
| الملف | الدور |
|---|---|
| `Ics`, `Classifier`, `Brief`, `Plan`, `Urls`, `EventCodec`, `Net` | منطق صافي بلا Android، مغطّى بالاختبارات |
| `Engine` | الجلب + إطلاق الملخص والتذكيرات + إعادة الجدولة |
| `Scheduler`, `AlarmReceiver`, `BootReceiver` | تنبيه واحد متجدّد، مع تعويض ما فات |
| `Store`, `Secrets` | تخزين محلي، الرابط مشفّر |
| `MainActivity`, `SettingsActivity`, `Ui`, `Texts`, `BriefWidget`, `Notifier` | الواجهة والنصوص والإشعارات والويدجت |

## ملاحظات
- التنبيهات الدقيقة تحتاج إذن «Alarms & reminders» على Android 12+ (التطبيق بيشتغل بدونه بدقة أقل، وبالإعدادات في زر مباشر له).
- على بعض الأجهزة (شاومي، هواوي، أوبو...) لازم تفعّل «التشغيل التلقائي» وتخلّي البطارية «بدون قيود».
